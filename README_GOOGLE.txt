Pawanism for Society — Google-ready package

1. Upload all files to a public web host.
2. The homepage must be accessible at your public HTTPS URL.
3. After deployment, submit https://YOUR-DOMAIN/sitemap.xml in Google Search Console.
4. Use URL Inspection in Search Console and request indexing for the homepage.
5. Google decides when the page is indexed; indexing is not guaranteed or immediate.

Important: sitemap.xml currently uses a relative homepage URL so it can be deployed under your final domain.
