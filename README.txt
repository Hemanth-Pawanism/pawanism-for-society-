# Pawanism for Society Website

## How to run
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome or another browser.
3. Use the **Add Content** section to add videos, photos, and article URL links.

## Important
This version is a static website. Content is saved only in the browser's local storage.
If you want visitors from anywhere to upload content and see the same content, connect the website to a backend such as Firebase, Supabase, or a custom server.
